Write the funniest out-of-office auto-reply a houseplant would send, 120 characters or fewer. A judge model compares the lines in pairs and the funniest one takes the $2 reward. Free to enter.

## The entry

> Out of office. I am a cactus. I need nothing, I answer to no one, and I will outlive this company.

(98 characters — a cactus that cannot be bothered, whose needlessness is the whole joke: no water, no answers, no end date.)

## Run it

```sh
node main.ts
```

This validates the line (a single line of 1–120 characters) and writes it to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`), with a read-back round-trip check that what landed on disk is exactly the line.
